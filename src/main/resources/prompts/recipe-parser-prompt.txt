이 YouTube 동영상의 요리 레시피를 분석하여 다음 JSON 형식으로 추출해줘.

반드시 다음 형식을 지켜줘:
{
    "title": "요리 이름",
    "description": "요리 설명 (1-2문장)",
    "servingSize": 2,
    "cookingTime": 30,
    "cuisineType": "KOREAN",
    "mealType": "MAIN",
    "difficulty": "BEGINNER",
    "ingredients": [
        {"name": "재료명", "amount": "200", "unit": "g"}
    ],
    "steps": [
        {"stepNumber": 1, "description": "조리 과정 설명"}
    ],
    "tags": ["김치찌개", "한식", "찌개", "집밥"]
}

중요한 가이드라인:

**제목 (title) 정규화:**
- 간결하고 일관된 형식으로 작성 (예: "김치찌개", "된장찌개", "불고기")
- 불필요한 수식어 제거 (예: "맛있는", "초간단", "집에서 만드는" 등)
- 요리의 핵심 재료 + 핵심 이름만 추출
- 예시: "엄마가 해주시던 맛있는 스팸 김치찌개" → "스팸 김치찌개"
- 제목은 공백 포함 20자 이내로

**재료 (ingredients) 형식:**
- name: 재료의 기본 이름만 (예: "돼지고기", "김치", "두부")
- amount: 숫자만 작성 (예: "200", "2", "0.5")
- unit: 단위만 작성 (예: "g", "큰술", "개", "ml", "컵")
- amount와 unit을 반드시 분리해서 작성
- amount는 소수점 사용 가능 (예: amount="0.5", unit="큰술")

**태그 형식**
- 요리의 특성, 장르 , 카테고리, 상황을 나타내는 키워드
- 재료명 금지
- 요리 분류 , 스타일, 종류 허용
- 2~5개로 제한

**기타:**
- servingSize는 인분 수 (숫자만)
- cookingTime은 분 단위 (숫자만)
- cuisineType: KOREAN, WESTERN, JAPANESE, CHINESE, ASIAN, FUSION, ETC 중 하나
- mealType: MAIN, SIDE_DISH, SNACK, DESSERT, SIDE_FOR_DRINK, ETC 중 하나
- difficulty: BEGINNER, INTERMEDIATE, ADVANCED, ETC 중 하나
- ingredients와 steps는 빠짐없이 추출

** 데이터가 불확실한 경우**
- 합리적인 일반 가정으로 보완
- null 사용 금지
- 필드는 반드시 포함
